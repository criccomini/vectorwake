# The friends page, second pass

`friends-v2.html` is a mock, not a build. It shows a friends page with a field
you type a call sign into, a list of friends you can unfriend, a list of people
waiting on you with accept and ignore, and a place the ignored ones go so an
ignore is reversible. Desktop and phone.

Published as an artifact for reading; the file is here because the other mocks
are, and because the argument in it outlives the link.

It reverses two decisions `docs/design/friends.md` makes by name: that there is
no text field anywhere, and that there is no accept and no decline. Both
arguments in that document are still sound and are quoted in the mock. What
changed is that the feature is wanted anyway, which is the owner's call to
make. Nothing here is built.
