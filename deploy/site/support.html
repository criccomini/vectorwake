Private account help

Join the Vectorwake Discord and send a private message to a member with the admin role. Use this route for account deletion, privacy requests, moderation appeals, or anything that should not be posted in public.

Include the generated call sign and a short description. Never send a password or device secret. An admin may ask you to prove control through an action inside the game.

Support is run by a small project team and has no guaranteed response time. Account and privacy requests have a target response time of 30 days.

Bugs and technical problems

Open a public issue in the Vectorwake repository. Include the browser or operating system, what you expected, what happened, and steps that reproduce the problem.

Do not post passwords, device secrets, private account information, or security vulnerabilities in a public issue. For a security problem, ask an admin on Discord for a private contact before sharing details.

Lost access

Vectorwake does not collect email addresses and has no email recovery. A signed-in device can change the pilot's password. If you lose both the password and every signed-in device, the account may not be recoverable.

Community reports

The game has no player chat. For a Discord message, use Discord's built-in report tools. For impersonation, cheating, ban evasion, or disruptive play, contact a Vectorwake admin privately with the call sign, approximate time, and zone.

Parents and guardians

If you believe a child under 13 has used Vectorwake, contact an admin privately. Include the generated call sign if you know it. The account and identifiable activity will be investigated and removed according to the deletion process.
